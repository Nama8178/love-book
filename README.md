# 📖 Our Love Story — 3D Memory Book Website

An interactive, breathtaking 3D memory book created for celebrating your love story with your girlfriend. Built with **Three.js**, **React**, **Tailwind CSS**, and **PageFlip 3D physics engine**.

---

## ✨ Features

- 🌹 **Realistic 3D Book Turning & Physics**:
  - Genuine page-peeling, curling paper physics, corner dragging, and soft shadows.
  - Realistic leather hardcover binding with gold-embossed foil, corner ornaments, and golden heart latch.
  - Keyboard navigation (Arrow keys `←` / `→`) and mobile touch swipe support.

- 🌌 **3D Three.js Romantic Environment**:
  - Floating golden stardust and drifting 3D rose petals.
  - Warm bokeh candlelight glows responding gently to mouse movement (parallax effect).
  - Candlelight flicker ambiance toggle.

- 🎵 **Enchanted Audio Engine (Zero Latency, Works Offline)**:
  - Realistic paper turn rustle sound synthesized via Web Audio API.
  - Ethereal romantic music-box piano melody (toggle on/off).
  - Heartbeat pulse & magical sparkle sound effects.

- 📸 **Rich Memory Chapters**:
  1. **Front Cover**: Ornate gold foil with your names & "Click to Open" heart clasp.
  2. **Dedication / Ex-Libris**: Handwritten dedication, vintage archive stamp.
  3. **Chapter 1 — The Serendipity**: Vintage Polaroids with scotch tape & story of the first day you met.
  4. **Chapter 2 — Wandering Together**: Travel ticket / boarding pass stub & sunset road trip memories.
  5. **Chapter 3 — Reasons My Heart Chose You**: 6 sweet reasons cards & her portrait.
  6. **Chapter 4 — Unfiltered Smiles**: 35mm film strip with candid snapshots & funny memories.
  7. **Chapter 5 — The Secret Love Letter**: An interactive 3D envelope resting on the page that unseals to reveal a handwritten love letter!
  8. **Chapter 6 — Our Journey in Time**: Real-time live counter calculating the exact **Days, Hours, Minutes, and Seconds** you have loved each other.
  9. **Chapter 7 — Sacred Promises & Forever**: Sacred vows and an interactive proposal button with a celebratory confetti cascade!
  10. **Back Cover**: Embossed golden insignia.

- 🛠️ **Built-in Customizer Modal ("Personalize")**:
  - Change his & her names (e.g., Mayank & her name).
  - Change anniversary / first met date.
  - Upload your own pictures directly from your computer or paste image links (stored securely in `localStorage`).
  - Edit captions, memories, and write your own heartfelt love letter.

- 🔍 **Interactive Photo Lightbox**:
  - Click on any Polaroid or photo to view it full screen with romantic details and heart reactions.

## 🚀 How to Run Locally

1. **Install dependencies** (already installed in project):
   ```bash
   npm install
   ```

2. **Start the local server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your web browser.

3. **Build for production**:
   ```bash
   npm run build
   ```

## 🎁 How to Deploy & Send to Your Girlfriend

You can host this website online for free so you can text her the link:

### Option 1: Vercel (Easiest & Free)
1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository and click **Deploy**.
4. You will get a live link like `https://our-love-story.vercel.app` to share with her!

### Option 2: Netlify (Free Drop & Deploy)
1. Run `npm run build` inside this project.
2. Drag and drop the generated `dist` folder into [Netlify Drop](https://app.netlify.com/drop).
3. Instant live link in 10 seconds!
